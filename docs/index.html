Claves del éxito en videojuegos con datos de IGDB

Este proyecto recorre todo el ciclo de ciencia de datos para entender qué factores se asocian al éxito de un videojuego, con foco en apoyar a estudios independientes (indies) en la toma de decisiones.

Ver objetivos Ir a conclusiones

Datos

Videojuegos, géneros, plataformas, empresas y métricas de éxito extraídas desde la API de IGDB.

Análisis

Limpieza, EDA, visualizaciones y modelos para entender qué separa a un juego exitoso del resto.

Acción

Recomendaciones aterrizadas para estudios indies: qué priorizar al lanzar un nuevo juego.

Objetivos del proyecto

Aquí pega tu texto de objetivos (general y específicos). Deja claro qué pregunta de negocio quieren responder y para quién están pensando las recomendaciones.

Objetivo general

Identificar qué características (plataforma, género, fecha de lanzamiento, etc.) se asocian al éxito de un videojuego y cómo esto puede guiar a estudios independientes en sus decisiones.

Objetivos específicos

  • Caracterizar el ecosistema reciente de videojuegos usando datos de IGDB.
  • Evaluar qué variables se relacionan con mejores métricas de éxito.
  • Construir un modelo que estime la probabilidad de éxito de un juego.
  • Traducir los resultados en recomendaciones prácticas para estudios indies.

Datos & Metodología

Resume aquí de forma simple cómo obtuvieron los datos, qué tablas usaron, y el flujo general (ETL, limpieza, EDA, modelado). No es necesario entrar en todo el detalle técnico del notebook.

1. Extracción de datos (ETL)

Uso de la API de IGDB para descargar información de juegos, géneros, plataformas y compañías, guardando los datos en formato reproducible.

2. Limpieza & transformación

Normalización de columnas, manejo de listas incrustadas (géneros, plataformas), filtrado por ventana temporal y eliminación de registros con información insuficiente.

3. EDA y selección de variables

Exploración de distribuciones, correlaciones y definición de las variables más informativas para el modelo de éxito.
